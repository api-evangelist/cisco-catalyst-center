# Cisco Catalyst Center

> Cisco Catalyst Center (formerly DNA Center) is a customer-deployed, intent-based networking controller for enterprise campus, branch and wireless networks. It exposes a northbound REST Intent API at /dna/intent/api/v1, an Assurance data API at /dna/data/api/v1 and a system API at /dna/system/api/v1, authenticated with a 60-minute X-Auth-Token obtained by exchanging HTTP Basic credentials. Because the controller runs on the customer's own appliance, there is no shared vendor API host: the base URL is https://{catalyst-center-host}. Cisco publishes 27 OpenAPI 3.0 documents covering the Assurance surface (185 operations) and a first-party Apache-2.0 MCP server bundling 516 generated tools.

## APIs

- [Cisco Catalyst Center Assurance & Intent API](https://developer.cisco.com/docs/catalyst-center/): Northbound REST API for inventory, sites, provisioning, software image management, SD-Access, compliance, event subscriptions and Assurance analytics. Base URL https://{catalyst-center-host}/dna/intent/api/v1
- [Cisco Catalyst Center MCP Server](https://github.com/cisco-en-programmability/catc-mcp-oss): First-party open-source MCP server, self-hosted via Docker; streamable HTTP at http://localhost:7001/v1/mcp or stdio. No Cisco-hosted remote endpoint.

## Notes

- Cisco publishes OpenAPI only for the Assurance surface. The wider Intent API is documented on DevNet but has no anonymously fetchable machine-readable contract; 446 of the 516 tools in Cisco's own MCP bundle hit paths with no published OpenAPI.
- No idempotency key, no OAuth scopes, no RFC 9457 problem details, no Sunset/Deprecation response headers, no published rate-limit reference page, and no A2A agent card.
- The MCP server is self-hosted and adds no authorization layer: it executes every bundled tool with the permissions of the configured Catalyst Center account.
